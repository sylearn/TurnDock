# 02 · 体验设计

## 1. 三层入口

```text
系统通知 ──点击/快捷键──▶ 快速回复面板 ──展开 ⌘E──▶ 完整收件箱
（知道有事）             （几秒完成一次交接）          （看完整交接、处理多条）
```

| 入口 | 尺寸 | 内容 |
|---|---|---|
| 通知 | 系统 | 来源 · 项目 · 问题首行。同一请求只通知一次 |
| 快速回复面板 | 560×460，可调 | 只显示最早一条待回复：来源条、问题（可滚动）、选项、输入框、快捷回复。底部提示“还有 N 条” |
| 完整收件箱 | 默认 1080×740，最小 760×520 | 左侧队列 + 右侧单一阅读/回复列 |

全局快捷键（默认 ⌃⌥Space，可改、可关；⌥⌘Space 已被 Finder 搜索占用）唤出快速面板。面板失焦不自动关闭、不改变请求状态；Esc 收起。

按宿主设置提醒方式：**仅通知**（默认）/ **弹出面板** / **静默**（只在菜单栏计数）。习惯寸止弹窗的用户可把常用宿主设为弹出。

## 2. 回合卡（交接的排版）

交接的阅读顺序按判断流程排列，而不是按 AI 写作的顺序：

```text
导出模块完成，CSV 与 JSON 均可用            ← 标题（宋体）
✓ 单元测试 54/54   ✓ 类型检查   – 大文件 未运行
? Excel 打开中文 CSV 需要你确认              ← 验证：先回答“能不能信”
┃ 风险与待定                                 ← 左侧警示线，不做色块
┃ · CSV 无 BOM，旧版 Excel 可能乱码
下一步
(●) 给 CSV 加 BOM 并补兼容测试  [推荐]   1   ← 推荐项预选，⌘↵ 即确定
( ) 改为临时文件 + 原子重命名            2
这一轮做了什么                               ← 细节放最后，长时折叠为预览
```

- 不滚动就能看到标题、验证、风险和下一步（已在 1080×820 预览中验证；默认 1080×740 窗口待原生实测）。
- 交接中隐藏快捷回复；输入框默认两行，用于补充要求或写新方向。
- “拒绝”在交接中叫“先停下”，确认对话框说明 AI 会说明当前状态并等待新指示。

## 3. 键盘模型

所有快捷键在输入法合成（composition）期间失效；在输入框内只保留带修饰键的组合。

| 键 | 作用 |
|---|---|
| ⌘↵ | 发送回复；交接中推荐项已预选，直接按即接受推荐 |
| 1–9 | 选择第 N 个选项（输入框外）；单选时直接选中，多选时切换 |
| ⌥1–⌥9 | 发送第 N 条快捷回复（提问类请求；输入框有内容时改为追加） |
| J / K 或 ↓ / ↑ | 切换上下请求（收件箱，输入框外） |
| ⌘L | 稍后处理（保留草稿，切到下一条） |
| ⌘⇧⌫ | 拒绝 / 先停下（弹确认） |
| / | 搜索（收件箱） |
| ⌘E | 快速面板 ↔ 收件箱 |
| Esc | 关闭最上层浮层；面板中为收起。从不取消请求 |

## 4. 版式

- **一条阅读列**：问题、上下文、选项、输入框共用同一宽度（最大 720px），左对齐。不出现“文字窄、卡片宽”。
- **框架最薄**：macOS 使用 overlay 标题栏；窗口顶部只有一条 44px 工具栏，显示来源、项目、连接状态。窗口内不放品牌名。
- **队列紧凑**：每条 64px，两行：第一行来源标识 + 标题；第二行项目 · 状态 · 等待时长（右对齐）。
- **回复区固定**：问题区独立滚动，回复区始终可见；长消息不会把发送按钮挤出视口。
- **字号**：问题标题 20/28（快速面板 17/24），正文 14/22，辅助 12/16。不出现 11px 以下的中文。

┌──────────────┬───────────────────────────────────────────────┐

## 5. 视觉方向：棋与石

回合的本义是轮流行棋。视觉只把力气用在一处：**棋子**。

- **实心墨子 ●** 表示轮到你（等待你回复）；**空心 ○** 表示已交还给 AI 或在等 AI 来取。它出现在队列、托盘计数和窗口标题里，本身就是状态信息，不是装饰。
- 其余元素保持安静：青瓷灰的石色底、近白的阅读纸面、墨色文字、一种强调色。
- 避开两种常见默认：靛蓝冷灰的 SaaS 配色，以及暖米色底配陶土色。

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--stone` | `#ECEEEA` | `#121514` | 窗口底、侧栏 |
| `--sheet` | `#FAFAF8` | `#1A1E1D` | 阅读列 |
| `--ink` | `#16191A` | `#E8ECEA` | 正文、墨子 |
| `--ink-2` | `#555C5A` | `#A3ABA8` | 次级文字（5.9:1 / 7.8:1） |
| `--rule` | `#DADDD7` | `#2A302E` | 分隔线（装饰） |
| `--edge` | `#868C88` | `#69716E` | 输入/选项边界（3.3:1 / 3.4:1） |
| `--signal` | `#0E6A60` | `#5FC9B9` | 唯一强调色：松烟青，用于主按钮、选中、焦点 |
| `--signal-ink` | `#FFFFFF` | `#06201C` | 强调色上的文字 |
| `--warn` | `#8A5300` | `#E2B05A` | 未在等待、交付未知 |
| `--danger` | `#B3261E` | `#FF8F86` | 拒绝、失败 |

- **字体**：问题标题用系统宋体（Songti SC / SimSun），像一张递到手里的便笺；正文与界面用系统黑体（苹方 / Segoe UI / 微软雅黑）；代码用 SF Mono / Menlo / Consolas。不加载在线字体，不用等宽字体做标签。
- **来源标识**：宿主名称加一个小几何标记（◆ Claude Code、▲ Codex、■ Cursor、● 其他），颜色只是辅助。
- **元信息靠排版区分**（字重、颜色、位置），不用“A · B · C”式的中点串联，不用全大写标签。
- **动效只有三处**：新请求落子（120ms）、发送状态变化、面板展开。`prefers-reduced-motion` 时全部关闭。

## 6. 状态与文案

文案先说“现在是什么情况”，再说“你能做什么”。

| 状态 | 列表标签 | 详情提示 | 主要动作 |
|---|---|---|---|
| 等待中（调用正在等） | 等待中 | — | 发送 |
| 未在等待（调用已超时返回或断开） | 未在等待 | AI 当前没有在等这条回复。你仍可以回复，AI 下次用 request_id 来取时会收到 | 发送（存为待领取） |
| 待领取 | 待领取 | 回复已保存，等 AI 来取 | 查看回复 |
| 已交付 | 已交付 | 回复已交给 AI 的连接（不代表 AI 已执行） | — |
| 交付未知 | 交付未知 | 回复发出时连接断开，无法确认 AI 是否收到。AI 再次来取时会重新交付 | 复制回复 |
| 已拒绝 | 已拒绝 | AI 收到了明确的拒绝 | — |
| 调用方取消 | 已取消 | AI 那边取消了这次提问，回复不会再发出 | 复制草稿、归档 |
| 已过期 | 已过期 | 超过等待上限，没有向 AI 表示同意 | 复制草稿、归档 |
| 已关闭 | 已关闭 | 你关闭了这条请求，AI 来取时会被告知“没有回复” | — |
| 保存失败 | — | 草稿还没保存，请先复制 | 复制、重试 |

## 7. 无障碍

- Tab 顺序：队列 → 问题 → 选项 → 输入框 → 快捷回复 → 操作。焦点环 2px `--signal` + 2px 偏移。
- 选项是真正的 radio / checkbox；队列是 listbox；状态变化通过有界 live region 播报。
- 200% 缩放、最小窗口下，选项、输入框与发送按钮都可达。
- 对比度：正文 ≥ 4.5:1；控件边界、焦点 ≥ 3:1。每次改 token 都用脚本复算。
