# 05 · 一步一步实施

不以“功能都画出来了”作为完成标准。每关列交付物、验证和停止条件；上一关的风险未关闭，不扩张下一关功能。阶段顺序固定，日历工期在 M0 后根据实测估算。

## M0 · 先验证最难的技术假设

1. 新建 Rust workspace 与严格 TypeScript 前端工程，锁定依赖；配置 format、lint、typecheck、单元测试与构建 CI。
2. 将请求/提交/取消状态机独立成无 UI 的 domain 模块；用假时钟测试 24 小时，不让 CI 每次实际等待一天。
3. 写一个假 MCP 客户端，支持两条连接、相同 RPC ID、取消、突然断线、输出管道关闭。
4. 建立轻量 stdio bridge 与本机 IPC 最小握手；验证多个 bridge 只唤醒一个桌面协调进程，端点不对公网暴露。
5. 试验 Tauri 的自定义命令权限和恶意消息隔离；确认 capability 约束实际生效。
6. 基线测量冷启动、驻留内存、bridge 成本、长 Markdown；记录机器/系统/构建类型/样本，不写空泛“性能大幅提升”。

交付：可运行协议试验、状态机测试、性能基线、锁定依赖、CI。

通过条件：100 次提交/取消竞态只有一个有效结果；两会话不串线；断线不报告同意；消息不能触发未授权原生命令。失败时先简化/调整架构，不先美化设置页。

## M1 · 最小真实闭环

1. SQLite 初始迁移、请求记录、草稿与提交快照；集中写入与错误处理。
2. 桌面最小窗口显示一条真实 `zhi` 请求、纯文本回复、明确拒绝。
3. 接入实际目标客户端，核对 `initialize`、`tools/list`、`tools/call`、取消和输出内容块。
4. 接入第二个客户端，验证相同 RPC ID 的隔离、关闭窗口不取消、退出应用有提示。
5. 连通阶段落盘，暴露 handed_off / unknown 的真实区别。

交付：仅供开发使用的本地桌面版本；真实工具请求到回复端到端录屏和协议轨迹。

通过条件：离开后能回来回复；关闭调用方后不向新会话错投；不存在隐藏提示词；正式返回结构通过旧 `zhi` fixture。一个客户端的成功不代替所有客户端兼容。

## M2 · 完整回复体验

1. 按设计 tokens 实现侧栏队列、上下文、详情、固定回复区域与聚焦窗口。
2. 加入明确单选/多选、空态、等待、断线、过期、取消、投递失败、历史详情。
3. 草稿按请求隔离、去抖保存与切换前保存；保存失败提示和复制退路。
4. 安全 Markdown 渲染、代码语言按需加载、长内容折叠、链接打开策略。
5. 主题、键盘、IME、屏幕阅读器、200% 缩放与最低窗口尺寸。
6. 与本轮原型对照截图：信息层级一致，不要求逐像素照抄浏览器外壳。

交付：主流程可用且能解释异常的界面。

通过条件：十条并行请求切换不丢草稿；长消息不遮挡发送区；输入法确认不提交；键盘可完成全流程；关闭快捷键立即失效。

## M3 · 图片、隐私与可靠性

1. 图片粘贴/拖放/文件选择进入同一附件管线：签名与解码检查、限额、预览、真实 MIME。
2. 同一 ID 单次删除；多附件提交快照冻结，发送中不可改写已提交内容。
3. 用户可控历史保留与删除；附件孤儿回收、磁盘预算、日志脱敏。
4. 暴力并发、取消/提交竞态、磁盘满、数据库忙、进程崩溃、系统睡眠恢复测试。
5. 在目标宿主进行一次真实 24 小时等待验证；记录宿主自己的限制，不能只靠模拟时钟。
6. 依赖审计逐项判定可达性，修复高风险可达项；不只统计 CVE 数量。

交付：安全与恢复测试包、实际长等证据、图片回归用例。

通过条件：原项目已复现的 HTML 执行、双重删图、MIME 错标、禁用快捷键仍触发均有阻止回归的测试；任何异常不转换为授权。

## M4 · 迁移与首个可安装版本

1. 整理 CLI 路径与应用 bundle，bridge 和 UI 成套签名；配置诊断输出不得包含密钥/正文。
2. 生成 macOS 签名与公证安装产物，验证干净机器安装、启动、退出、卸载。
3. 与寸止并排安装；生成新的 MCP 配置片段，用户显式切换后才禁用旧条目。不要自动覆盖用户配置。
4. 审查升级模式：Homebrew 安装由 Homebrew 管理；独立安装使用签名更新或明确手动更新。
5. 验证无网、损坏更新包、旧 bridge、安装中断、迁移失败、恢复上一版本。
6. 发布前名称/包标识检查、许可/依赖归属、版本说明、已知限制、故障诊断文档。

交付：有签名的 macOS 候选包、迁移与回退步骤、最终验收清单。

通过条件：真实设备/目标 MCP 客户端运行通过；旧寸止仍可回切；没有未解释的权限或静默数据上传。没有签名条件时只能标测试版，不能伪称正式发布。

## M5 · 有需求再做

Windows/Linux 实机适配；明确授权的 Telegram/手机通道；可选协议任务支持。每一项先有独立威胁模型与验收，不把它们塞进首版阻塞核心体验。
