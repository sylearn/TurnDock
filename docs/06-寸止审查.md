HTML 测试证明消息可执行 JS，不等于已经实测原生任意命令执行或泄露密钥。更新路径已有单文件备份和 Unix rename，问题是信任验证、双二进制一致性和完整恢复，不是“完全无原子替换”。Homebrew 下载有 sha256，不能把自定义更新缺陷扩大到 Homebrew 安装路径。

取消测试使用安装版本复制件与隔离延迟 UI stub：调用发出后取消，ping 仍正常，约 5 秒后原调用返回成功。因此没有证据声称整个 MCP 事件循环卡死；有证据表明取消未传递到等待中的 UI 子进程。MCP 对取消使用 SHOULD，报告的是可靠性缺口，不夸大成所有客户端都必然协议违规。

## 性能与工程基线

- Vue 3 / Tauri 2 / Rust 的选择本身没有过时到必须抛弃；问题更多在职责耦合、状态与边界。
- 正式前端 `pnpm build` 通过；入口约 824.69KB（gzip 229.25KB），Markdown 块约 1072.65KB（gzip 353.44KB）。不是所有块都同时载入，但首屏与高亮依赖值得拆分。
- `test:ui:build` 失败；缺正式 typecheck 和测试流水线。无修复模式 lint 发现 5 个空白格式错误，严重性远低于功能问题。
- 环境未发现 Cargo，**没有完成 Rust 编译/原生端测试**。
- 依赖审计生产图中出现 14 条路径匹配报告（9 high / 5 moderate）；不能等同 14 个可利用漏洞。Markdown typographer/linkify 相关 DoS 需做可达性与有界输入测试，编译器/SSR 类条目不能直接套到桌面运行时。
- 可选 ACE 代码搜索会扫描并向配置服务发送代码；默认关闭，不应称为默认泄露。它与核心人机交互职责不一致，因此新项目不纳入首版。

## UX 结论

寸止证明了“让 AI 的回合停下来等人”的价值，最高频的用法是每轮结束前的检查点与“继续”。重写保留这一核心（见 01 场景 A），并补齐：多宿主队列、来源与项目、宿主超时下的续等、独立草稿、如实的交付状态。不沿用的部分：隐藏组装的增强提示词、选项一律多选、文本里附带 base64 预览、固定的连接文案。

## 对第一版重写方案的审查（已并入 01–05）

1. 原方案依赖单次工具调用等待 24 小时，但 Codex 等宿主默认 60 秒超时 → 改为请求与调用解耦的续等协议（04）。
2. 原方案把产品定位为“请求收件箱”，弱化了回合检查点 → 场景 A 成为最快路径，保留可见的快捷回复（01、02）。
3. 缺少集成层（instructions、规则片段、宿主配置）和与 MCP elicitation 的差异说明 → 补入 01、05。
4. 视觉为通用靛蓝冷灰、框架过厚、队列过高、阅读宽度不一 → 改为“纸与墨”、三层入口、单一阅读列（02）。
5. 技术选型过于抽象 → 锁定具体库，Markdown 移到 Rust 渲染净化（03）。
