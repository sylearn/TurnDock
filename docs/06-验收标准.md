# 06 · 质量、性能与验收

所有数字是首版目标，不是本轮测得结果。达不到时先记录瓶颈与调整依据，不为追分砍掉正确性。

## 性能预算

参考环境：Apple Silicon、16GB 内存、当前支持的 macOS，release build，无调试工具；每项记录具体型号/系统，冷启动与热启动分开。至少 30 次取 p50/p95，驻留观察 30 分钟；老设备与 Windows/Linux 单独列结果。

| 指标 | 初始目标 | 测量方法 |
|---|---|---|
| 应用冷启动到可操作 | p95 ≤ 1.5s | 进程启动至窗口接受键盘，不能仅测网页 DOM |
| 常驻状态新请求可见 | p95 ≤ 150ms | bridge 收到请求至 UI 绘制，排除用户反应时间 |
| 任务切换 | p95 ≤ 100ms | 100 条列表、10 条等待、每条 10KiB 正文 |
| 输入响应 | p95 ≤ 50ms | 长正文 + 4 张图片，IME 与普通键盘分别测 |
| 空闲 CPU | 平均 < 1% 单核 | 已稳定 5 分钟后连续采样；无轮询循环 |
| 桌面总驻留内存 | ≤ 180MiB | 包含应用关联 WebView 进程，不能只报 Rust 主进程 |
| 每个空闲 bridge | ≤ 25MiB | 多客户端增量成本 |
| 首屏前端 JS | gzip ≤ 180KiB | 按入口传递依赖计算，异步 Markdown/高亮单独记录 |
| 100 次开关/切换后增长 | 稳定后 ≤ 10% | GC/缓存稳定后比较，重复三轮 |

不以压缩包小推导真实内存小。大消息渲染超预算时先做长度限制、折叠、按需高亮；只有列表规模证明需要才引入虚拟化。附件处理离开 UI 主线程，数据库大查询分页。

## 必须阻止的故障

| ID | 场景 | 必须结果 |
|---|---|---|
| S01 | Markdown 含 onerror/script/javascript URL | 不执行，无原生调用、无远程隐式请求 |
| S02 | 调用方内容请求 shell/任意文件 | 权限拒绝，正文只是文字 |
| S03 | 同名/相同 RPC ID 来自不同连接 | 请求与回复严格隔离 |
| R01 | 用户数小时未回复 | 无自动同意、无隐藏继续 |
| R02 | 两窗口重复发送 | 一个有效提交；第二次显示已有结果 |
| R03 | 取消与提交各 1000 次随机竞态 | 只有一个有效终态，不复活已取消请求 |
| R04 | 写出后 ACK 丢失 | 标 delivery_unknown；禁止盲重发 |
| R05 | 桌面/bridge/客户端分别被终止 | 状态与持久化一致；旧连接不能伪恢复 |
| A01 | 两张 JPEG 删除第一张 | 剩余第二张，ID/字节不变 |
| A02 | JPEG/PNG/超限/伪造 MIME | 正确类型；不合法明确拒绝 |
| U01 | 快捷键禁用/重新绑定/IME | 禁用立即有效；无旧监听器；输入法不误发 |
| U02 | 长代码/200%缩放/最低窗 | 选项、输入与发送均可达 |
| D01 | 磁盘满/数据库 busy | 不假报保存成功；可复制草稿 |
| D02 | 清理历史 | 正文、附件、缩略图一致删除，日志不泄露 |
| P01 | 损坏或未签名更新 | 不安装；现有版本仍可运行 |

## 自动化层级

1. 每次提交：format、lint（不自动改文件）、TS strict typecheck、Rust clippy、纯状态机/组件测试、依赖锁一致性。
2. 每个 PR：真实子进程 MCP 集成、IPC 权限负例、SQLite 迁移、前端构建、亮暗关键截图、axe 检查。
3. 候选发布：原生窗口/通知/快捷键/系统凭据库、签名与安装、实际宿主长等、故障注入、多实例内存与 CPU。
4. 人工验收：真实中文任务、屏幕阅读器、键盘-only、长内容、用户恢复路径。自动化无违规不等于辅助功能完全合格。

测试 fixtures 不含用户仓库或凭据。复现命令、commit SHA、构建配置、截图/录屏和断言一起保存。没有 Rust 工具链时应明确“未运行”，不让前端成功掩盖后端未验证。

## 迁移验收

- 新旧应用可并存，但同一客户端只启用一个同名 `zhi` 提供者，避免工具歧义。
- 新配置路径独立；迁移预览只显示差异，不读取/导出无关密钥。
- 回切只恢复已确认的配置片段；不删除新应用历史或旧寸止数据。
- 至少验证用户实际使用的客户端，再验证第二个独立宿主；列出版本与已知超时。

## 发布阻断项

消息执行代码、请求错投、取消变成同意、草稿静默丢失、签名绕过、真实 MIME 错标、无法区分投递未知、生产凭据明文泄漏，任一未关闭均不得标正式版本。非关键动画和额外主题不能阻塞安全闭环，也不能用来代替它。
