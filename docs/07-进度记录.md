# 07 · 进度记录

## 2026-10-20 · M0 与 M1 主体

### 已实现

| 范围 | 内容 |
|---|---|
| `turndock-core` | 请求规格与校验、状态机（phase / delivery / attached）、IPC 帧、数据路径 |
| `turndock-broker` | 协调器 actor（唯一写入者）、SQLite（WAL、迁移、事务）、Unix socket（目录 0700、socket 0600、对端 UID 校验、协议版本握手）、Markdown 渲染与 ammonia 净化、图片签名校验、优雅关闭、终端版开发协调器 |
| `turndock-mcp` | `ask_user` / `zhi` / `await_reply`；按宿主的等待预算；progress 心跳；取消转发；broker 不在时 8 秒内明确失败；**连接中断时在预算内自动重连续等** |
| 桌面应用 | Tauri 2.12 外壳嵌入 broker；收件箱（队列、阅读列、选项、回复、草稿、图片、快捷回复、拒绝、关闭、稍后）；快速回复面板；托盘计数；系统通知；全局快捷键；设置与接入（配置片段、规则片段）；亮暗主题；自定义命令按 capability 授权 |
| 设计预览 | `preview.html` + Tauri `mockIPC` 示例数据，用于浏览器内视觉审查 |
