## 2026-10-20 · 重新定位为“交接点”

依据：按请求计费已不是主流，记忆与代码检索有成熟的 skill / MCP。产品从“别让 AI 提前结束”转为“每一轮结束时的结构化交接”。详见 01。

- `ask_user` 选项支持 `recommended`。
- 回合卡界面：标题 → 验证 → 风险 → 下一步（推荐预选）→ 这一轮做了什么（长时折叠）；交接中隐藏快捷回复，“拒绝”改为“先停下”。

## 2026-10-20 · 分发：一行安装、一个命令、可更新

### 架构

```text
TurnDock.app
├── Contents/MacOS/turndock-desktop   界面 + broker
└── Contents/MacOS/turndock           命令行入口（bundle.externalBin）
/usr/local/bin/turndock → 上面的 turndock（安装脚本或 Homebrew cask 创建）
```

- `turndock`：终端里打开回合窗口；`turndock mcp`：MCP stdio 服务。接入命令对所有用户相同，不含个人路径。
- 安装：`install.sh`（下载 → SHA256 校验 → 装进「应用程序」→ 链接命令 → 询问是否接入已安装的 Claude Code / Codex），再次运行即更新；Homebrew cask 用 `binary` 自动链接命令。
- 拖拽 dmg 安装的用户：应用启动时在 `/usr/local/bin` 可写的情况下静默补上命令，否则在点击「接入」时请求一次管理员授权。开发构建不碰系统目录。
- 更新：tauri-plugin-updater 读取 Releases 上的 `latest.json`，用内置公钥验证 minisign 签名后替换应用包；命令随包更新。私钥只在本机 `~/.tauri/turndock.key` 与 GitHub Secrets。
- 设置页「接入」只剩客户端列表：Claude Code、Codex 一键运行接入命令；Cursor 用其 deeplink 让 Cursor 自己确认；其余复制 JSON。检测只读配置文件。

### 已验证

- `cargo test --workspace`、clippy、`vue-tsc`、Vitest 通过。
- 本地 `scripts/release.sh` 产出 universal 应用（arm64 + x86_64）、dmg、更新包与签名、latest.json、cask。
- `install.sh` 在临时目录安装、更新、卸载（`TURNDOCK_FROM` 本地产物，`TURNDOCK_APP_DIR` / `TURNDOCK_BIN_DIR` 指向临时目录）。

- GitHub Actions：CI（ubuntu：Rust 测试与 clippy、前端类型检查与测试）通过；推送 `v0.1.0` 标签后 Release 工作流在 macOS 上构建成功，产物包括 universal dmg、更新包与签名、latest.json、install.sh、SHA256SUMS，并自动提交了 Homebrew cask。
- 仓库 https://github.com/sylearn/TurnDock 已公开。

### 未验证

- 应用内更新的真实升级路径（需要 0.1.1）。
- 未做 Apple 签名与公证：浏览器下载的 dmg 首次打开会被 Gatekeeper 拦截（安装脚本与 cask 会去掉隔离标记）。
