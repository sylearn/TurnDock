## 实测结果

| 检查 | 结果 | 限制 |
|---|---|---|
| JavaScript 语法 | `node --check` 通过 | 不等于正式 TypeScript 检查 |
| 14 项交互断言 | 14/14 通过 | 使用 DOM 事件，不代表原生端或真实 MCP |
| 草稿隔离 | 两任务填不同内容，切回保持各自内容 | 原型 localStorage，不是生产 SQLite |
| 单选/多选 | 单选最多一个、多选可选两个 | 原型 fixture |
| 图片删除 | 添加两张 PNG，删第一张后只剩一张 | 原型只检查浏览器类型/大小，正式解码验证尚未实现 |
| 稍后处理 | 草稿保留、请求继续等待 | 无后台定时器与真实宿主 |
| 拒绝 | 取消对话框不提交；确认后独立拒绝状态 | 无真实投递 |
| 对话框重复打开 | 清空旧 returnValue；上次确认不污染下次关闭 | 修复并加入回归断言 |
| 输入法防误提交 | 合成 isComposing 键盘事件不发送 | 真实 macOS 中文输入法仍需正式应用验收 |
| 断线 | 文字可查、发送/拒绝/附件禁用 | 模拟断线 fixture |
| 搜索 | 搜索 Atlas 仅返回一个匹配任务 | 本地样本集 |
| 模拟发送/历史 | 禁止再次发送，已处理列表有记录 | 明确标注未真实投递 |
| 亮暗主题 | 截图人工检查；axe 4.12.1 均 0 violations | 各有 1 类 incomplete，5 个节点须人工复核；不宣称完整无障碍认证 |
| 600×800、390×844 | 无横向溢出，发送区留在视口内 | 长内容在上方独立滚动，需滚动查看后续选项 |
| 1440×1000、聚焦模式 | 布局正常，侧栏收起/恢复 | 不是原生窗口测试 |

对比度补充计算（WCAG 相对亮度）：亮色次级文字/白底 5.37:1；暗色次级文字/画布 7.48:1；亮色强调/白底 6.05:1；暗色强调/画布 8.53:1；亮色输入框边界/白底 3.02:1，暗色边界/画布 3.82:1。axe 的不确定节点主要为装饰字符和伪元素背景，以上配色计算用于补充，而非宣称覆盖全部状态。

## 重复检查

先在原型“原型说明与重置”中重置演示，再在隔离浏览器运行：

```sh
agent-browser --session turndock-check open file:///Users/sylearn/Desktop/TurnDock/design/prototype/index.html
agent-browser --session turndock-check eval --stdin < /Users/sylearn/Desktop/TurnDock/design/prototype/check.js
agent-browser --session turndock-check close
```

脚本会改变当前浏览器的演示记录。它不自动重置，避免清除使用者正在看的草稿。不要在原型输入敏感数据。
